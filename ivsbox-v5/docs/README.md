## 本目录计划放什么

1. `interfaces-frozen.md` —— 架构文档 §18 要求的九类冻结接口的实际取值
   （平台帧格式、UART 帧、无线/模组型号、摄像机清单、媒体上限、音频硬件、OTA 范围、
   远程访问边界、BSP 能力与资源预算）。
2. `bsp-capability.md` —— M0 的 BSP 能力清单结果（FFmpeg / ALSA / SQLite / TLS /
   cgroup / nftables / gpsd / 4G 拨号栈 / 交叉工具链 prefix）。
3. `resource-budget.md` —— 每进程 RSS / 句柄 / 带宽实测与预算（缺口 G1）。
4. `decisions/` —— 决策记录（每次改架构都留一条：背景、选项、结论、影响章节）。

## 冻结顺序建议

按缺口清单的关闭顺序推进：M0 先冻结资源预算、提权机制、平台 TLS 定位，
再进 M1 编码。**在这些定下来之前，代码里的上限参数一律写 TODO，不要拍数字。**
