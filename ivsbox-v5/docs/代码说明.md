# IVSBox 代码说明

> 本文件是**每次写代码后的代码说明载体**，规则见项目根目录 `AGENTS.md` 规则 4。
> 目的：不看代码也能知道**干了什么事、解决了什么问题**。
> 记录顺序：**倒序**（最新在最上方），只追加，不修改、不删除历史条目。
> 时间格式：`YYYY-MM-DD HH:mm`。纯文档修改不必在此登记。

---

## 记录格式模板

```markdown
## YYYY-MM-DD HH:mm　<一句话标题>

- **涉及文件**：`相对路径/文件`（新增 / 修改）
- **干了什么事**：按文件或函数列出关键逻辑，说明数据流与调用关系。
- **解决什么问题**：改动前的现象 / 缺口，改动后的行为。
- **为什么这么做**：方案选择理由、被否掉的替代方案（如有）。
- **影响范围**：会被影响的其他模块、接口、配置、上板差异。
- **未覆盖 / 风险**：已知未处理的边界、TODO、待实测项。
- **验证方式与结果**：编译命令、单测、板端命令、实测输出。
```
