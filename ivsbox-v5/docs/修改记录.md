  - `ivsbox-v5/scripts/bsp-survey.sh`（新增，同上）
  - `.gitattributes`（新建，源码与脚本强制 LF）
- **问题 / 目的**：两件事。① 工作副本迁移到 `F:\debug\T113_TCP\ivsbox-v5` 时漏带两个文件，而它们是 S01 开工的前置资产：`bsp-capability.md` 是架构文档 §14 要求的"立项初期 BSP 能力清单"，`bsp-survey.sh` 是生成该清单的板端盘点脚本；缺失会导致 BSP 能力（libc 类型、串口、看门狗、ffmpeg、可写分区）无据可依。② 仓库本机 `core.autocrlf=true` 且无 `.gitattributes`，`bsp-survey.sh` 检出到 Windows 工作副本后行尾会变成 CRLF，一旦 scp 到板子上执行，`/bin/sh` 会因 `^M` 报错，脚本直接跑不起来。
- **处理方式**：从旧脚手架目录原样复制这两个文件到工作副本，保持内容不变、避免与旧副本分叉；在仓库根新增 `.gitattributes`，规定 `*.c/*.h/*.sh/*.cmake/*.md` 等一律 LF、`*.bat/*.cmd` 保留 CRLF、二进制不转换。
- **验证结果**：`scripts/bsp-survey.sh`（7923 字节）、`docs/bsp-capability.md`（6710 字节）已就位；`.gitattributes` 生效后 `git add` 不再报 LF/CRLF 转换告警。下一步在板端执行 `./bsp-survey.sh > /tmp/bsp-survey.txt 2>&1` 回填 §2 各表。
