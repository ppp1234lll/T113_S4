开发板说明文档

TQT113 开发板 · 2026-10-16 · 面向现场使用人员

连板子：账号 root，密码 embedsky（用串口线连的话不用密码）。

看参数：参数都在 /opt/EmbedSky/config/ 里，用 cat 就能看。

看网页：浏览器打开 http://板子IP/（管理页默认 admin / 88888888，首次登录必须改密码）。

1. 怎么登录开发板

连接方式地址账号密码
串口线串口 115200 8N1root不用密码，接上直接进去
网线 + SSH板子的 IProotembedsky
网线 + Telnet板子的 IProotembedsky

板子的 IP 是多少：本产品规定板子使用固定 IP（不由路由器自动分配）， 默认 192.168.1.64，怎么设置见第 2.5 节。

想在板子上确认当前地址，接串口进去后敲：

ip addr show eth0

看 inet 后面那一串就是。

改密码：连上后敲 passwd，按提示输两遍新密码即可。

2. 设备参数一览（全部字段与出厂默认值）

2.1 参数放在哪里、怎么看怎么改

全部参数都在 /opt/EmbedSky/config/ 目录下，一共三个文件：

文件里面是什么
EmbedSkyProgress.ini主要参数：网络、时间、看门狗、升级、开机自启程序
EmbedSky.ini设备平台型号、GPIO 引脚
appinit.ini桌面上那些图标的清单

查看（在板子上敲，三个文件同理）：

cat /opt/EmbedSky/config/EmbedSkyProgress.ini

修改：用 vi 打开改，改完重启。

vi /opt/EmbedSky/config/EmbedSkyProgress.ini
reboot

板子桌面上也有自带的设置程序（Network、SystemInfo 等），点着改和手工改是同一份数据，用哪个都行。

2.2 主要参数：EmbedSkyProgress.ini

下表是这个文件的全部内容，一行都不缺。"出厂默认值"就是板子刚烧完时的值。

[network_0] —— 第 0 个网口（eth0）

字段名出厂默认值说明
device_nodeeth0网卡名
enable1是否启用本段配置。1＝启用（本产品用这个）
ip_modestaticIp取 IP 的方式。udhcpc＝自动获取，staticIp＝用下面的固定 IP（本产品用这个）
ip192.168.1.64固定 IP 地址（自动获取时不生效）
netmask255.255.255.0子网掩码
gateway192.168.1.2网关
dns114.114.114.114DNS 服务器
mac_modecpuidMAC 的来源。cpuid＝按 CPU 编号自动生成
mac2E:A2:9E:EF:43:43MAC 地址（mac_mode=cpuid 时不生效）

[network_1] —— 第 1 个网口（eth1）

本板没有第二个网口，所以这一段出厂只有网卡名和模式，其余留空、不启用。

字段名出厂默认值说明
device_nodeeth1网卡名
enable0不启用
ip_modeudhcpc自动获取
ip（空）未填
netmask（空）未填
gateway（空）未填
dns（空）未填
mac_modecpuid按 CPU 编号自动生成
mac（空）未填

[system] —— 系统

字段名出厂默认值说明
datetime_enable_p0开机是否强制设成下面的固定时间。0＝否
datetime2020-02-18 15:55:11固定时间值
nettiming_enable_p1是否开网络校时（NTP）。1＝开
nettiming_serverntp.sjtu.edu.cnNTP 服务器地址
led_enable_p0是否启用指示灯。0＝关
led_selectled1用哪一个指示灯
network_num1启用几段网络配置。1＝只用 [network_0] 这一段

[bootapp] —— 开机自动运行的程序

字段名出厂默认值说明
bootapp_num1自动启动几个程序
bootapp_name1/opt/EmbedSky/bin/TQPDA_Main第 1 个自启程序（就是那个桌面）

[watchdog] —— 看门狗

字段名出厂默认值说明
rootfswd_enable_p0根文件系统看门狗。0＝关
rootfs_timeout5上面那个的超时时间（秒）
sofewardWD_enable_p1软件看门狗。1＝开
softward_timeout10软件看门狗超时时间（秒）
softward_interval3喂狗间隔（秒）

注：字段名里的 sofeward 是文件里原本的拼写，照抄即可，别"改错别字"。

[ota] —— 升级

字段名出厂默认值说明
ota_local_enable_p0本地升级。0＝关
ota_nameTQT113升级包识别名
ota_network_enable_p0网络升级。0＝关
ip_porthttp://192.168.1.96/升级服务器地址

2.5 网络：只使用固定 IP（不用自动获取）

本产品规定板子使用固定 IP，不由路由器自动分配。相关字段都在 EmbedSkyProgress.ini 里，取值如下：

段字段名应设为说明
[network_0]enable1启用本段网络配置
[network_0]ip_modestaticIp取值就是 staticIp，不要写 udhcpc
[network_0]ip192.168.1.64板子固定 IP（按现场实际填）
[network_0]netmask255.255.255.0子网掩码
[network_0]gateway192.168.1.2网关
[network_0]dns114.114.114.114DNS 服务器
[system]network_num1启用 1 段网络配置

改完 reboot。用桌面上的 Network 设置程序改更省事，它会自动帮你写这几个字段。

本版镜像出厂就是上表的取值：板子一上电就是 192.168.1.64，不会去向路由器申请地址。§2.2 里 [network_0] 与 network_num 的“出厂默认值”已按同一版镜像更新，两处是一致的。

要接到别的网段，就改 ip、netmask、gateway 这三项， 改完重启板子。IP 改了以后要用新地址访问（旧地址不再响应）。

3. 网页界面

出厂自带的网页

项目内容
打开地址http://板子IP/
账号无
密码无

打开就能看，不用登录。

注意：这个网页只是天嵌自带的演示页，不能用它设置设备。要改参数请看第 2 节。

板子上跑我们自己的程序（ivsbox）时：

项目内容
打开地址http://板子IP/
默认账号admin
默认密码88888888
首次登录必须先修改密码，改完才能进其它页面
密码规则长度 8-12 位；必须同时包含大写字母、小写字母、数字
以后想改密码进主界面后点左下角的 改密（要先输原密码）

默认密码 88888888 全是数字、不符合上面的规则，所以第一次登录一定会被要求改密码， 这是正常的，不是故障。

新密码格式不符合规则时，页面会弹提示：

请输入正确的密码格式：
密码长度:8-12
密码由数字+大写英文字母+小写英文字母组成

照这个要求重新输入即可。例：Abc12345 符合，88888888 不符合。

4. 常见问题

现象怎么办
网页打不开、ping 也不通先确认板子 IP（见第 1 节），再确认板子已经开机启动完成
忘了密码接串口线直接就能进（不用密码），进去后敲 passwd 重设
FTP 连不上出厂镜像没开 FTP 服务，属正常现象
参数改了没生效需要重启，敲 reboot
参数改乱了想恢复出厂照第 2 节"出厂默认值"那一列抄回去，重启即可
不知道板子 IP 是多少板子用固定 IP，默认 192.168.1.64（见第 1 节、第 2.5 节）
登录后让我改密码首次登录必须改密码。新密码 8-12 位，且大写、小写、数字都要有
