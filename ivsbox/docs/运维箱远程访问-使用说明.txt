运维箱远程访问（单文件版） 1.1.3
==========================

> 想按步骤上手，先看同目录的《一步一步使用说明.md》；
> 本文件是功能与参数参考手册。

双击「运维箱远程访问.exe」就能用：不需要任何脚本，不需要装任何软件，
也不需要先把 frpc 摆到同目录 —— 程序自己带。

第一次运行
----------
程序内嵌了 frpc 和一把专用密钥，首次运行自动释放到
%LOCALAPPDATA%\ivsbox-remote\，不需要你操作。
Windows 可能提示"未知发布者"，选「仍要运行」即可。

**1.1.3 起出厂就带好现场配置**：服务器 47.95.22.96:7000、当前令牌、
默认设备 SN=0A19B4、下拉框里的 0A19B4 / 0B2CC1 —— 都是内嵌的。
新机器第一次双击打开就能直接「连接并打开」，不用再点「服务器设置」填任何东西。
（只有换服务器、或令牌被轮换过，才需要重新填，见下文「服务器设置」。）

换设备：选哪个 SN 就连哪台（1.1.0 新增）
------------------------------------
窗口最上面一行就是设备切换条：

    设备 SN [ 0A19B4  v ]  [切换]  [服务器设置]   服务器 47.95.22.96:7000

  - 下拉框里是**用过的 SN**（近的在前）；
  - 直接敲一个新的 SN 也行，敲完点「切换」；
  - 选中下拉项的那一下就已经切了，不用再点按钮；
  - 切完状态栏会显示「当前设备 XXXX（服务器 a.b.c.d:7000）」。

为什么以前必须重打包、现在不用了：
    设备侧的 stcp 代理名是 SN（serverName），握手钥匙是
        secretKey = 小写hex( MD5(SN + 令牌) ) 的前 8 字节
    以前这份钥匙是打包进 exe 里的死值，换台设备就得重新编译。
    1.1.0 起 SN、服务器地址、端口、令牌都能在界面上改，
    程序每次都用当前 SN **现算**这把钥匙、现写 visitor.toml，
    再让 frpc 按新配置重启 —— 所以一台电脑能管任意多台设备。

一次性灌一批 SN（可选）
----------------------
在 exe **同目录**放一个 sns.txt，一行一个 SN，# 开头是注释：

    # 现场设备
    0A19B4
    0B2CC1    3号箱
    0C3344

下次启动这些 SN 就都在下拉框里了（行尾的备注只当注释，不参与连接）。
删掉这个文件就恢复成只用历史记录。注意：SN 只能包含字母、数字、- 和 _。

服务器设置
----------
点「服务器设置」，三个字段：

    frps 地址    服务器公网 IP 或域名（默认 47.95.22.96）
    端口         默认 7000
    令牌         必须同时满足三处一致：
                   - 服务器 frps 的 auth.token
                   - 设备上保存的隧道令牌（Web「远程通道」页填的那个）
                   - 这里填的
                 三处只要有一处不同，frpc 会 login 失败或 visitor 连不上。

改完点「保存」立即生效（会按新令牌重算所有设备钥匙），不用重启程序。
这些值存在 %LOCALAPPDATA%\ivsbox-remote\remote.ini，下次启动沿用。

打开之后
--------
  列表        设备上配置的每一路摄像机，状态列会实时探测：
              可连接 / 网络不通 / 80 端口不通 / 探测失败
  连接并打开  建隧道并自动弹出浏览器（也可以直接双击某一行）
  设备 Web    打开设备本机管理页面（本地 18080）
  下载文件    打开 SD 卡文件浏览器（见下）
  断开        拆掉当前隧道（frpc 保留，下次选路更快）
  刷新        重新读摄像机列表并重新探测

列表里只显示「设备上真配了 IP」的路数
------------------------------------
显示几路，就是设备配置（Web「摄像机」页的 `camera.ch[N].ip`）里真填了几路。
设备只配 2 路，这里就只有 2 行，不会多也不会少。

1.1.0 及更早有个坑：读不到设备时程序会拿写死的 `.200/.106/.108` 兜底，
于是永远显示 3 路 —— 那第 3 路是编出来的，还会去探测一个根本没配的地址。
1.1.1 起这个兜底已删除：读不到就**空着**，并在状态栏末尾和日志里分成两句话：

    读不到设备配置（见日志）   → ssh 没通：设备在线/SN 选对/通道开启（见下面排障）
    设备未配摄像机 IP          → ssh 通了，但设备一路 IP 都没填

下载 SD 卡文件
--------------
点「下载文件」会打开一个文件浏览器，跟资源管理器一样操作：

  远程目录   顶部输入框。点「转到」直接跳过去，「上一级」往回退
  列表       名称 / 大小 / 修改时间，文件夹排在最前面，文件名后面带 /
  ..         列表第一行，双击回到上一层
  保存到     默认是「下载」文件夹；点「选择...」可以换成任意目录，
             「打开」直接打开那个目录看文件
  下载       双击某个文件 → 立刻下到「保存到」那个目录
             或者按住 Ctrl 多选几行 → 点「下载选中」批量下
             下载中按钮变成「取消下载」，下面那条进度条会走

  文件名太大或路径太长时，把窗口往右拖宽一点即可（列宽是自适应的）。

网络不通的会被拦住
------------------
如果摄像机没接线、没通电，或者 IP 和设备不在同一网段
（设备 eth0 是 192.168.1.120/24，摄像机却配成 192.168.2.x），
程序会直接弹「网络故障」并列出该查哪几条，不会建隧道，
也不会占用本地端口。

程序在建隧道之前会先在设备侧探一次（TCP 连 80，连不上再 ping），
所以"能不能连"在动手之前就有结论。

速度
----
隧道走 ssh 压缩（-C）。摄像机 Web 首屏约 6 秒（摄像机前端本身有
8.3 MB 的 JS/CSS，不压缩要 30 秒）；4G 上行约 250 KB/s。
本机走有线实测 SD 卡下载 1.3 MB/s。
看画面和下载不要同时做，两者抢同一条 4G 上行。

排障
----
%LOCALAPPDATA%\ivsbox-remote\ 里有三个日志：
  run.log      程序每一步的操作记录（先看这个）
  frpc.log     通道客户端日志（连不上服务器时看）
  tunnel.log   隧道那条 ssh 的输出（端口没起来时看）

"切了 SN 还是连不上"先按这三条分：
  0. 列表是空的，先看状态栏那行提示：
       "读不到设备配置（见日志）" = 下面 1~3 条里的一条
       "设备未配摄像机 IP"        = 设备 Web「摄像机」页没填 IP，与通道无关
  1. frpc.log 里 `login to server failed`  → 服务器地址/端口/令牌不对
  2. frpc.log 里 login 成功、但没有 `start visitor success`
                                           → 这台设备此刻没上线（设备侧 frpc 没连上服务器）
  3. 前两条都正常、ssh 报 `kex_exchange_identification`
                                           → SN 对不上：visitor 拿这把钥匙连到了别的代理，
                                             或设备侧代理名不是这个 SN
另外确认设备上已经装了本程序的公钥（DEPLOY 那一步），否则 ssh 连不上。

隐藏参数（命令行用，日常不用管）
  --selftest                  自检：不弹界面，跑完把结果写进 run.log
                              退出码 0 = 全通过
                              （含：钥匙黄金向量、切 SN 后配置是否跟着换、
                                免密登录、建隧道、列 SD 卡、下载并核对字节数）
  --sn A1B2C3                 本次直接用这个 SN 跑，不改 ini 里存的
  --shot 文件.bmp [毫秒]       把界面截图存成 BMP（文档配图用）
  --openset                   启动即打开「服务器设置」（配 --shot 截那个框）
  --opendl                    启动即打开下载窗口
  --dlpath /mnt/sdcard/snap   指定下载窗口的初始目录
  --dlw 1000 --dlh 640        按指定尺寸打开下载窗口

如果设备换了 IP 或者重装过
--------------------------
摄像机和设备地址都是从设备上实时读的，改完配置点「刷新」就行。
新设备上要能用，两件事：把 exe 的公钥装进设备的 /root/.ssh/authorized_keys，
再把 device 目录里的 cams.py / checkcam.py / camstat.py 按 DEPLOY.txt 放好。
