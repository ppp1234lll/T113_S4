# IVSBox 远程通道使用说明（令牌 / frpc / 运维箱访问）

> 适用：T113 运维终端 ivsbox ≥ 1.0.8，Web 界面「远程通道」页。
> 相关代码：`src/modules/tunnel/`（闸门）、`src/app/main.c`（令牌读写）、`src/modules/ctl/iv_ctl.c`（`tunnel.configure`）、`web/src/iv_web_api.c`（`/api/tunnel*`）、`web/static/app.js`（页面）、`scripts/frp.sh`（进程）。
> 生成工具：`tools/tunnel-keygen.html`（离线单文件）。

---

## 1. 一分钟上手

| 步骤 | 在哪 | 做什么 |
|---|---|---|
| ① | 运维箱/服务器 | 起 frps，`auth.token` 设成下面这个**令牌**，端口 7000 |
| ② | 设备 Web →「远程通道」 | 填 frps 地址、端口、令牌 → 勾「启用通道」→「保存并生效」 |
| ③ | 运维 PC | 打开 `tools/tunnel-keygen.html`，填设备 SN + 同一令牌 → 生成 `visitor.toml` 与 `connect.bat` |
| ④ | 运维 PC | `frpc.exe` + `visitor.toml` 放同一目录，双击 `connect.bat` |
| ⑤ | 运维 PC | `ssh -p 2022 root@127.0.0.1`，或 `pscp -P 2022 root@127.0.0.1:/mnt/sdcard/snap/x.jpg .` |

设备侧保存后 **≤5 秒**生效（`monitor.sh` 每 5 秒一轮，看到 `/tmp/frp.enabled` 就拉起 frpc）。
**不需要重启设备，也不需要重启任何服务。**

## 2. 令牌是怎么生成的

### 2.1 它是什么

令牌（token）是一串**双方共享的随机字符串**，不是设备算出来的：

```
secretKey = md5(设备SN + 令牌) 的前 8 字节 → 16 位小写 hex
```

设备把 `secretKey` 写进自己那份 `frpc.toml`；运维 PC 用**同样的 SN 和同样的令牌**算出同一个值，写进 `visitor.toml`。
两边对不上 ⇒ stcp 握手失败，而**两边都不会报"钥匙错"**（stcp 的设计如此）—— 所以令牌必须一字不差。

同一个令牌还要给 **frps 的 `auth.token`**：设备侧 frpc 就是用这个令牌向 frps 鉴权的
（`iv_tunnel.c` 渲染 `auth.token = "<令牌>"`），frps 配的是别的值就会 `authorization failed`。

> 一份令牌三处用：**设备**、**frps**、**运维 PC**。

### 2.2 生成方式（任选一种，结果等价）

**A. 设备 Web 页面**（现场最省事）
「远程通道」页 → 令牌框右侧「生成随机令牌」→ 32 位小写 hex，生成后明文显示，方便抄到 PC。

**B. 生成工具**（推荐，顺带把 PC 侧配置一起生成）
双击 `tools/tunnel-keygen.html` → 点「生成」。
本工具**完全离线**：所有计算都在浏览器里，断网、内网、隔离网都能用。

**C. 命令行**

```bash
openssl rand -hex 16                                   # 32 位小写 hex
python3 -c "import secrets;print(secrets.token_hex(16))"
```

### 2.3 硬性约束（设备侧强制，不是建议）

| 项 | 约束 | 违反时的表现 |
|---|---|---|
| 长度 | 1~63 字节 | 超长直接被拒，提示"令牌超长" |
| 字符集 | 只允许 `0-9 A-Z a-z - _ . ~ + / = @` | 被拒，提示"第 N 个字符不合法" |
| 换行 | 只取第一行，遇 `\r`/`\n` 截断 | 多行令牌只生效第一行 |
| 大小写 | **区分** | 大小写不同 = 不同令牌 = 钥匙不同 |

**为什么用白名单**：令牌会被直接拼进 `frpc.toml` 的双引号值里。带 `"` 会让引号提前闭合；
带换行能**注入任意配置键**（比如把 `localPort` 改成别的端口）；带 `#` 会让后面的行变成注释。
这三种都不会报"令牌非法"，只会表现为"frpc 起不来"或"转发了不该转的端口"。
校验落在 `iv_tunnel_token_valid()`，单测 `test_tunnel t10` 钉住。

### 2.4 示例

设备 SN = `0A19B5`，令牌 = `b11311b17bb3ebc6745837ae087776c9`：

```
secretKey = md5("0A19B5" + "b11311b17bb3ebc6745837ae087776c9")
          = f39f461b5e1499b9      # 只取前 16 位
```

自检命令（PC 上）：

```bash
printf '%s' "0A19B5b11311b17bb3ebc6745837ae087776c9" | md5sum | cut -c1-16
```

工具页与设备单测用的是同一个黄金向量：`md5("A120F"+"bird123")` 前 16 位 = `1239036bac71d702`。

### 2.5 换令牌会怎样

- 设备侧：写令牌 → 更新内存身份 → **作废正在开的会话**（旧钥匙配新配置只会"连得上连不通"）。
- 运维 PC 侧：`visitor.toml` 里的 `secretKey` 与 `auth.token` 必须同步换，否则 visitor 超时。
- 建议**一机一令牌**：令牌 + SN 就能推出 secretKey，等于远程入口的一半钥匙。

## 3. 设备侧配置（Web「远程通道」页）

字段与含义：

| 字段 | 配置键 / 落点 | 说明 |
|---|---|---|
| frps 地址 | `sys.tunnel.server.host` | 空 ⇒ 开不了通道（fail-closed） |
| frps 端口 | `sys.tunnel.server.port` | `0` 表示默认 7000 |
| 令牌 | `/mnt/UDISK/ivsbox/secure/tunnel.token`（0600） | **不是配置项**：配置是明文 JSON 且会整份导出给前端 |
| 有效期 | 会话参数 | 1h / 8h / 24h / 不过期；到期由 `ivsboxd` 与 `frp.sh` **各判一次** |
| 启用通道 | — | 勾上＝保存后立刻开 |

保存动作在后台按固定顺序执行（顺序错了会"令牌写进去了、frps 还是旧地址"）：

1. 地址/端口变了 ⇒ `/api/config/apply`（带**现取**的版本号，只提交变了的键）
2. `/api/tunnel/config` → ctl `tunnel.configure`：写令牌 → 换钥匙 → 作废旧会话 → 按需要 enable

页面**不回显**设备已有的令牌（只显示"已配置（N 位）"）。要换就重填一份，不改就留空 ——
留空等于"不动"，不会被当成"清空"。

状态卡还会显示：通道开关、剩余有效期、设备 SN、frps 落点、`frpc.toml` 与标记文件路径、累计开启/拒绝次数、上次会话时长与结束原因。

## 4. 运维 PC 侧

### 4.1 生成两份文件

`tools/tunnel-keygen.html` → 填 SN / 令牌 / frps 地址端口 / 本机 bindPort（默认 2022）→
「计算并生成配置」→ 下载 `visitor.toml` 与 `connect.bat`。

`visitor.toml` 的关键字段：

```toml
serverAddr = "47.104.250.225"
serverPort = 7000
auth.token = "<令牌>"          # 与设备、frps 同一份

[[visitors]]
name       = "0A19B5-visitor"  # 本机标识，随便取但要唯一
type       = "stcp"
serverName = "0A19B5"          # **必须等于设备 SN**（设备的代理项名就是 SN）
secretKey  = "f39f461b5e1499b9"
bindAddr   = "127.0.0.1"
bindPort   = 2022
```

### 4.2 frpc 从哪来

设备侧有 `/usr/bin/frpc`（同一套 frp），运维 PC 用**同版本**的 `frpc.exe` 即可，
放在 `connect.bat` 同目录，不需要安装、不需要服务。

### 4.3 通道里能做什么

设备侧**只转发本机 sshd(22)**，其余都在 SSH 里做：

```bat
:: 登录设备
ssh -p 2022 root@127.0.0.1

:: 下载文件（抓拍图 / 录像 / 日志）
pscp -P 2022 root@127.0.0.1:/mnt/sdcard/snap/20261104_183000.jpg .
pscp -P 2022 root@127.0.0.1:/mnt/UDISK/log/2026-11-04/18.log .

:: 看摄像机（摄像机在设备的内网里）：先把摄像机 RTSP 映到本机
ssh -p 2022 root@127.0.0.1 -L 9090:192.168.1.200:554
:: 然后本机播放 rtsp://127.0.0.1:9090/...
```

> 注意：`127.0.0.1:9090` 是**运维 PC 侧** `ssh -L` 出来的端口，不是设备上的服务。
> 设备上不存在 9090/9091/9092。

## 5. 验证清单

设备侧（浏览器或 ssh）：

- [ ] 「远程通道」状态卡：通道＝已开启，剩余有效期不为 0
- [ ] 令牌＝已配置（N 位）
- [ ] `ls -l /etc/frp/frpc.toml /tmp/frp.enabled` 两个都在
- [ ] `cat /etc/frp/frpc.toml` 里 `secretKey` 与工具算出的 16 位**完全一致**
- [ ] `ps -o comm | grep -x frpc` 有输出
- [ ] `/mnt/UDISK/log/frpc.log` 里是 `login to server success` 一类，不是 `authorization failed`

PC 侧：

- [ ] `connect.bat` 窗口里 frpc 打印 `start proxy success` / `start visitor success`
- [ ] `ssh -p 2022 root@127.0.0.1` 能进

## 6. 任何新板子烧写后为什么能直接用

1. 页面是**静态资源**，随固件一起打包（`make package` 拷 `web/static`），烧完就有「远程通道」页。
2. 配置键 `sys.tunnel.server.host/port` 在默认值表里（出厂空/0），不用改固件就存在。
3. 令牌文件缺失是**正常初始态**（`token file absent` 只是 WARN，不是故障）；在页面上填一次即落盘，之后重启仍在。
4. `frpc` 二进制在系统镜像里（`/usr/bin/frpc`），`monitor.sh` 的通道守护段一直都在。
5. `tunnel.configure` 会**自己建** `<secure>` 目录（0700），不依赖工厂工具先跑过。

> 唯一仍然需要人工的是：**填一次 frps 地址与令牌**。这是故意的 —— 令牌是共享秘密，
> 出厂预置一份等于所有设备共用同一把钥匙。

如果量产要预置 frps 地址（不含令牌），改 `src/modules/config/iv_config.c` 里
`sys.tunnel.server.host` 的默认值即可；**令牌不要预置**。

## 7. 排错：三种"连不上"分得开

| 现象 | 位置 | 原因 / 处理 |
|---|---|---|
| 状态卡「未开启」，`ps` 无 frpc | 设备 | 地址为空 ⇒ 闸门拒绝；或令牌未配置；或有效期已过。看 `tunnel.enable` 的返回话术 |
| 有 frpc，日志 `connect to server error` | `frpc.log` | frps 地址/端口错，或服务器没起、路由不通 |
| 有 frpc，日志 `authorization failed` | `frpc.log` | frps 的 `auth.token` 与设备令牌不一致 |
| visitor `start visitor success` 但连不通 | PC | `serverName`≠SN，或 `secretKey` 不一致（换过令牌没同步） |
| SSH 能连、摄像机连不上 | PC | 摄像机 IP 是设备内网地址；确认 `-L` 的映射目标可达（设备上 `ping 192.168.1.200`） |
| 保存报"配置已被别处改动"（e=-3） | 设备 | 别处先改了配置 ⇒ 刷新页面重试（页面会用新版本号） |

通道"闪一下就没了"：看有效期是否设成很短、或 `tunnel.tick` 判了过期；
`ivsboxd` 重启后会 `restore` 认领标记（通道不因主控重启而断），这是预期行为。

## 8. 安全边界

- 通道类型是 **stcp**：frps 上不开任何公网端口，扫描器看不到；访问方必须有同一把钥匙。
- 设备侧固定只转发 `127.0.0.1:22`，**摄像机 IP 永远进不了** `frpc.toml`。
- 有效期是硬闸门：`ivsboxd` 的 `tick()` 与 `frp.sh` 各自独立判过期，主控被 kill 也关得掉。
- 令牌不回显、不进配置、不进日志；`config.all` 导出里也没有它。
- 已知欠账：`<secure>` 目录目前不是真正的机密存储（F8 密钥分离未实现），与 `camera.ch.N.pass` 同类。
