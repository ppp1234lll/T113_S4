============================================================
include  ——  公共头文件根目录（当前仅 ivsbox/ 一个子目录）
============================================================

【目录作用】
  include/ 是工程的公共头文件根目录，供各层源码 #include。
  编译统一带 -Iinclude，故包含方式固定写作 #include "ivsbox/xxx.h"。
  当前本目录下只有 ivsbox/ 一个子目录，全部公共头都在其中。
  本目录不放任何 .c 实现，只放声明与宏；实现分布在 src/ 各层。

【文件说明】
  ivsbox/               全部公共头文件子目录（详见 include/ivsbox/readme.txt）

【约定与注意事项】
  - 头文件保护宏统一为 IVSBOX_<NAME>_H，并配 extern "C" 包裹（兼容 C++）。
  - 只为跨层/对外可见的接口建头；模块私有头不放到这里。
  - 新增头文件无需登记构建系统，-Iinclude 是全局生效的。
