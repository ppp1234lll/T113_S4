============================================================
src/modules/access  ——  门磁 / 门锁控制与审计（规划，未实现）
============================================================

【目录作用】
  规划为箱门相关功能的归属地：开锁请求的鉴权与去重、门磁事件（UART 上送）的
  即时上报、以及开锁/门事件的审计入账（`control.db`）。联动抓图的**触发**在本
  模块，抓图本体在 M6。属模块层（`libivmodules.a`），预期经 `iv_link` 下发
  电源/门锁命令、经 `iv_status` 反映门状态。

【文件说明】
  当前为空占位目录，仅 `.gitkeep`（尚无源码）。

【实现状态】
  未实现。规划于功能开发计划 M4-S4.5（门锁与门事件）。

【约定与注意事项】
  - 规划口径：开锁请求带**事务号 + 来源鉴权 + 有效期 + 去重表**；门磁事件立即
    上报平台、不等抓图；审计入 `control.db`；**断电后锁状态语义按硬件安全要求
    处理，不假设默认上锁**。
  - 注意采集板协议**无请求号/事务号**（架构 §18.2），重放保护需在本层落实。
  - 上游依赖（待确认）：UART 门锁/门磁命令字与硬件通道分配、审计表结构。
