============================================================
src/modules/device  ——  摄像机与交换机档案：ONVIF 发现、一机一档（规划，未实现）
============================================================

【目录作用】
  规划为设备档案管理：发现并建立摄像机/交换机的"一机一档"，为探活、SNMP、
  ONVIF、媒体等模块提供稳定的设备身份。档案主键＝MAC/序列号，IP 视为可变属性。
  属模块层（`libivmodules.a`）。

【文件说明】
  当前为空占位目录，仅 `.gitkeep`（尚无源码）。

【实现状态】
  未实现。规划于功能开发计划 M4-S4.2（ONVIF 与一机一档）。

【约定与注意事项】
  - 规划口径：选型优先复用镜像内已有 SOAP/HTTP 组件（无则登记待安装清单，先做
    直连 HTTP `GetDeviceInformation`）；WS-Discovery 走 UDP 组播
    `239.255.255.250:3702`，挂 Reactor；档案导出**不含凭据**，口令只存 `secure/` 引用。
  - 单次回调约束（架构 §4.2）：回调内禁止同步 ONVIF/长 IO，重活进慢任务池。
  - 上游依赖（待确认）：架构 §18.4（品牌/数量/RTSP 地址/ONVIF 能力清单）。
