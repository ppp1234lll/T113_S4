============================================================
src/modules/netmgr  ——  网络管理：rtnetlink 监听、双 WAN 切换状态机（规划，未实现）
============================================================

【目录作用】
  规划为网络管理：无线优先、故障切有线、稳定回切的确定性状态机（架构 §7.2）。
  属模块层（`libivmodules.a`）。
  注意：配套的 **rtnetlink 监听（S3.1）落点在 `src/hardware/iv_netlink.c`**，
  不在本目录。

【文件说明】
  当前为空占位目录，仅 `.gitkeep`（尚无源码）。

【实现状态】
  未实现。规划于功能开发计划 M3-S3.3（双 WAN 状态机）；S3.1 的 rtnetlink 在
  `src/hardware/` 层实现。

【约定与注意事项】
  - 规划状态：`WIRELESS_UP / DEGRADED / SWITCH_TO_WIRED / WIRED_UP /
    SWITCH_TO_WIRELESS / BOTH_DOWN`；参数（fail_n / ok_n / hold_s）进配置。
  - 切换执行 §7.2 **七步事务**：冻结低优先级发送 → netlink/策略路由切默认出口 →
    关闭绑定旧接口的 TCP（含平台连接与远程流）→ 新接口重连 → 鉴权恢复 →
    按优先级补传 → 稳定期后恢复媒体大流量。
  - 上游依赖（待确认）：架构 §18.3（4G 模组、拨号栈、双 WAN 网卡名）。
