============================================================
src/modules/ota  ——  升级包格式与验签（设备侧只验不改）
============================================================

【目录作用】
  IVSBox 的 OTA 侧模块（进 `libivmodules.a`）。只承担两件事：
  ① 定义**升级包格式**；② 提供**设备侧唯一入口的验签器**。
  按架构分工，`ivsboxd` 只协调升级（收命令 / 下载 / 上报进度），验签与安装归
  `updater/`（`ivsbox-updater`）—— 本模块只回答"这包该不该收"，
  **不下载、不解压、不安装、不切换版本**（那些是 M7-S7.2 / S7.3）。

【文件说明】
  iv_ota.c        清单行式解析（纯计算、**不改输入缓冲**）＋ 版本号工具 ＋ 九步验签
                  ＋ `mmap` 文件版 ＋ 内置公钥占位；头文件 `include/ivsbox/iv_ota.h`
  对应单测      tests/unit/test_ota.c（13 组）。**签名侧不在设备代码里**：
                设备只验签，测试用 OpenSSL 现造两把密钥并对造出的包签名。

【包格式（简版；权威口径在头文件）】
  头 16B（`magic="IVSOTA01"` ＋ u32 `manifest_len` ＋ u32 `payload_len`）
  ＋ 清单（行式 ASCII，`key=value`，末行也要 `\n`）
  ＋ 负载（各文件按清单顺序首尾相接）
  ＋ Ed25519 签名 64B（**覆盖签名之前的全部字节**）
  **总长必须严格等于 `16 + manifest_len + payload_len + 64`**：多一字节（夹带）或
  少一字节（截断）都判非法 —— 不做宽容解析。

【验签顺序（固定）】
  结构 → 清单 → 负载长度 vs 清单合计 → 公钥 → **签名** → 型号 → 硬件版本区间 →
  软件版本（禁降级/同版本，且本机版本 ≥ `minrollback`）→ 逐文件 SHA-256。
  签名通过前**不采信清单的任何语义**；只做长度与格式的边界检查（否则读不到要验的字节）。
  被拒时同时给出本地负码（`iv_ret.h`）与 `iv_ota_reason_t`（诊断 / 上报用）。

【实现状态】
  已实现（M7-S7.1，2026-10-14）：格式与验签器落地；单测 13 组；VM 全量验证
  （`test`/`asan`/`tsan` 36/36、`host`/`analyze`/`arm` rc=0、`arm` 零告警）；
  反向证伪 10 条（型号 / 签名 / 硬件区间 / 公钥 / 降级 / minrollback / 逐文件摘要 /
  负载长度 / 路径围栏 / magic）全部抓出。
  **未做（如实登记）**：
    ① **量产发布公钥未部署** —— `iv_ota_builtin_pubkey()` 返回 `IV_ENOTSUP` 且输出全零，
       调用方按"无公钥"处理即**拒绝一切包**（fail-closed，绝不做"无密钥即免签"）；
    ② 装配层接线（收命令 / 下载 / 上报进度）随 **S7.2**；
    ③ **板端未复跑**（板子当时不在线）—— ARM 侧证据只到"交叉编译零告警 ＋
       `readelf -d` 见 `NEEDED libcrypto.so.1.1`"，**板端 rootfs 是否真有该 so 待现场核对**。

【约定与注意事项】
  - **密码学用 OpenSSL EVP（Ed25519），不自写椭圆曲线**：架构 §14 口径为"加密与签名
    复用项目现有可信密码库"；实测板端 sysroot 有 OpenSSL 1.1.1a（`EVP_PKEY_ED25519`
    可用）、宿主有 3.0.2。升级包**校验值**仍用 core 的自写 `iv_sha256`，两者分工，
    不做互相替代。（比照：`iv_sha256` 是"纯计算、无密钥"才自写。）
  - 因用第三方库，本模块**必须留在 modules 层**（core 纪律：只允许 libc）。
  - 两端 `mk/toolchain-*.mk` 的 `LDLIBS` 已加 `-lcrypto`；**Ed25519 要求 OpenSSL >= 1.1.1**。
  - 零 malloc、无全局状态；文件版走 `mmap(MAP_PRIVATE)`，**不写、不创建、不改该文件**。
  - 量产公钥**只写公钥**；私钥绝不入库（AGENTS.md 规则 3 第 6 条）。
