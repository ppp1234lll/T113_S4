============================================================
src/modules/probe  ——  统一探活引擎：链路 / ICMP / TCP / 应用层四层（规划，未实现）
============================================================

【目录作用】
  规划为主网、双 WAN、摄像机共用的**四层探活与统计判定**引擎，向 netmgr、
  device、recovery 等模块输出统一的可用性结论。属模块层（`libivmodules.a`）。

【文件说明】
  当前为空占位目录，仅 `.gitkeep`（尚无源码）。

【实现状态】
  未实现。规划于功能开发计划 M3-S3.2（统一探活引擎）。

【约定与注意事项】
  - 规划四层：链路层＝S3.1 rtnetlink 事件；网络层＝raw socket ICMP
    （需 `CAP_NET_RAW`）；传输层＝非阻塞 TCP connect 完成即断开；应用层＝
    心跳/RTSP OPTIONS/SNMP GET 任一。
  - 统一输出结构：状态、原因码、最近 RTT、滑动平均、丢包率、连续成败次数、
    最近成功时间。**ICMP 被禁（无 CAP 或被墙）时，TCP/应用层成功仍判可用**。
  - 单次回调约束（架构 §4.2）：回调内禁止同步阻塞探测，探测任务进慢任务池。
