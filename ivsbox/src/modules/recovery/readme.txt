============================================================
src/modules/recovery  ——  自愈策略引擎：确认→断电重启→验证→熔断（规划，未实现）
============================================================

【目录作用】
  规划为规则化的设备自愈引擎：按规则确认故障后，经采集板 UART 控制电源通道
  断电重启，并做恢复验证与熔断保护。属模块层（`libivmodules.a`）；动作经
  `iv_link` 下发（对接 S2.3 电源通道控制）。

【文件说明】
  当前为空占位目录，仅 `.gitkeep`（尚无源码）。

【实现状态】
  未实现。规划于功能开发计划 M4-S4.4（自愈策略引擎）。

【约定与注意事项】
  - 规划规则字段：目标 / 触发条件 / 确认方式 / 动作 / 电源通道 / 断电时长 /
    重试次数 / 冷却 / 时间窗 / 熔断上限。
  - 四道保护：冷却、每小时与每天限频、**上游关联**（≥N 台同类同时掉线先查交换机/
    主网，不动作）、超限熔断只告警。
  - 注意采集板协议**无事务号**，重启类动作重传可能被重复执行，须先 0xE1 回读
    状态或按幂等语义处理（见 link 模块说明）。
