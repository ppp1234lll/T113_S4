============================================================
src/modules/snmp  ——  SNMP 采集与品牌 OID 模板（规划，未实现）
============================================================

【目录作用】
  规划为交换机/设备的 SNMP 采集：按品牌/型号套用 OID 模板，采集结果映射到统一
  字段 schema，供平台上报与展示。属模块层（`libivmodules.a`）。

【文件说明】
  当前为空占位目录，仅 `.gitkeep`（尚无源码）。

【实现状态】
  未实现。规划于功能开发计划 M4-S4.3（SNMP 采集）。

【约定与注意事项】
  - 规划口径：优先 `net-snmp` 裁剪或轻量库（登记选型）；OID 模板按品牌/型号存
    配置；交换机标准 IF-MIB 打底，厂商扩展（温度/PoE）走模板；**模板缺失时报
    "未知型号"而非乱猜**；采集超时不阻塞（进慢任务池）。
  - 单次回调约束（架构 §4.2）：回调内禁止同步 SNMP 调用。
  - 上游依赖（待确认）：架构 §18.4（SNMP OID 清单）。
