运维箱助手 1.0.0  —  配置 · 令牌 · 远程连接，一个程序全包
================================================================

以前要开两个程序（通道配置 + 远程访问）再加一个网页生成令牌，
现在只开这一个：填「SN」和「口令」，点【连接设备】，剩下全是它自己做。


一、你只需要填两样
------------------------------
  设备 SN    左上角下拉框。常见的几台已经在里面，没有就直接敲（6 位左右，
             设备背面/系统信息里那串）。
  口令       设备 Web 的登录口令（账号固定 admin，不用填）。

  IP 地址、服务器地址、端口、令牌、通道开关 —— 都不用填。


二、第一次用，三步
------------------------------
  ① 填 SN（或从下拉里选）、填口令，点【连接设备】。
  ② 看下面第二行的摘要：出现「通道：开着 · 设备令牌 32 位 · 服务器 …」
     就对了；摄像机表格里各路的「状态」变成「可连接」。
  ③ 点某一路的【连接并打开】（或【设备 Web】），浏览器自动打开画面。

  日志区每一条都带时间，出问题时按它说哪一步没了。
  日志写着「先试上次记住的设备地址」＝它记得这台，直接就上；
  没记住就扫一遍本机网段（默认路由那段先扫，一般 3~4 秒）。


三、它自动做的六件事（点一次【连接设备】）
------------------------------
  1. 找设备：上次的地址先试，不行就扫本机网段里开 80 端口的机器，
     再逐个登录**核对 SN** —— 对的才认，绝不靠 IP 认设备（扫到别人的
     箱子也不会连错）。
  2. 对齐服务器：设备上报的 frps 地址与内置值不同，就按设备的改本机配置。
  3. 补令牌：设备**完全没有令牌**时，把本机这串下发过去（这是唯一会自动
     写令牌的情形，因为不写就一定连不上）。设备已有令牌但长度不同（大概率
     不是同一串）时它**不改**，只在日志里提示你去「生成令牌…」。
  4. 开通道：设备通道关着就打开（你点「连接设备」就是要用它）。
  5. 起本机通道：释放内置 frpc + 专用密钥到 %LOCALAPPDATA%\ivsbox-assist\
     并启动，等到本地 16000 端口监听上。
  6. 读摄像机：从设备读「配了几路」，再逐路探测通不通。


四、界面上的按钮
------------------------------
  【连接设备】   上面那六件事全做一遍。日常就点这一个。
  【服务器设置】 只在**换 frps 服务器**时才用（地址/端口/令牌）。
                 共用一个服务器的话，一辈子不用点。
  【开通道】     只开设备侧通道，不读摄像机。
  【关通道】     关掉设备侧通道（远程就进不去了）。
  【生成令牌…】  见下一节。
  【连接并打开】 把选中的那一路映射到 127.0.0.1:9090 并用浏览器打开。
  【断开】       断开已建的本机隧道（frpc 不退出，下次更快）。
  【设备 Web】   直连设备自己的管理页（看配置、日志、改参数）。
  【下载文件】   下载设备上的媒体/日志文件。
  【刷新】       重读摄像机列表和连通性。


五、【生成令牌…】三个按钮改的范围不一样
------------------------------
  令牌是服务器 frps 的 auth.token，**设备、本机、服务器三处必须同一串**。

  【只用于本机】         只改这台电脑。改完这台连不上任何设备 —— 除非你
                         本来就是要手工去改别处。
  【下发到设备（+本机）】改设备 + 这台电脑。**推荐**：服务器不动，两处一致。
  【连服务器一起改】     三处一起改。要填服务器 SSH 口令。
                         只有「要轮换密钥」时才用它。

  每次点之前会弹一句"这么改会发生什么"，看清再点。
  下发前它会**先读一次设备当前状态**，通道开着就保持开着、关着就保持关着，
  不会顺手把门关上或打开。
  「重新生成」只是换一串新令牌（32 位十六进制），不写任何地方；写完要点上面
  三个按钮之一才生效。


六、设备还在出厂口令怎么办
------------------------------
  新设备出厂口令是 admin / 88888888，服务端在没改口令前**只放行改密接口**，
  别的接口一律 403。助手会认出这种情况，直接弹框让你设新口令
  （8~12 位，同时含大写、小写、数字）。设完它会自己把刚才那步重做一遍，
  你不用回去再点一次。新口令会被记住，下次不用填。


七、连不上时按日志对号（都在日志区里）
------------------------------
  「本机网段没找到 SN=… 的 IVSBox（或口令不对）」
       先看口令对不对（同一个口令在浏览器能进吗）；再看网线：设备接在
       这台电脑的网口/同一台交换机上了吗。跨网段找不到 —— 用【服务器设置】
       旁边的地址栏手工填 IP（支持 IP:端口）。

  「设备 xxx 还在出厂口令状态」
       按第六节设新口令。

  「通道没起来」后面会跟三条排查（本机能不能上网 / 设备通电和 4G / 设备
       上的 frpc 有没有连上服务器）。最常见是**三处令牌不是同一串**。

  「通道就绪（本地 16000 已监听）」但摄像机「不可连接」
       这一半走的是隧道（stcp → 设备 22 端口）。说明设备 Web 那头没问题，
       问题在设备到摄像机那段网络，或者摄像机的 IP 在设备上填错了。

  日志里出现「令牌长度与设备不一致」的提示
       用【生成令牌…】→【下发到设备（+本机）】统一一次。


八、文件都在哪
------------------------------
  %LOCALAPPDATA%\ivsbox-assist\
      assist.ini      记住的 SN / 口令 / 设备地址 / 服务器 / 令牌
      frpc.exe        首次运行自动释放
      id_ed25519      专用密钥（只读自己）
      visitor.toml    按当前 SN 现算，不要手改
      run.log         最近一次的完整日志（报问题时把它发出来最快）

  想恢复出厂：把 assist.ini 删掉重开。
  exe 旁边放一份 sns.txt（每行一个 SN）可以批量灌 SN 列表，
  格式见包里的 sns.txt.example。


九、给支持人员的命令行（普通用户不用管）
------------------------------
  --sn <SN> --pass <口令>      指定设备和口令
  --devip <IP[:端口]>          跳过扫描，直接用这个地址
  --probe                      只读：定位 + 读设备状态，什么都不改
  --link                       等于点一次【连接设备】
  --on / --off                 开 / 关设备通道
  --token <32位>               直接下发令牌（设备 + 本机）
  --tokdlg                     只打开「生成令牌」对话框
  --newpass <口令>             出厂口令时自动改密（配合自动化）
  --shot <文件.bmp> [毫秒]     截图（自动化用）
  例：运维箱助手.exe --sn 0A19B4 --pass 你的口令 --probe
