============================================================
tools/provision  ——  出厂工装：写入设备 ID / MAC 等身份信息
============================================================

【目录作用】
  IVSBox 的量产工装（非常驻工具），负责在出厂环节写入设备身份。按计划 §S5.5：
  设备 ID / MAC / 调试服务器地址 / 加密套件 ID 等以定长二进制记录写入 eMMC
  `private` 裸分区（/dev/by-name/private），并对密钥/口令另行落盘；工具仅在工厂
  模式标记存在时可运行，不进日常自启。它独立编译，不参与 ivsboxd 的库分层。

【文件说明】
  本目录无直接源文件，只有下级源码子目录：
    src/    工装源码（入口 main.c，见 src/readme.txt）

【运行方式】
  make host / make arm    构建产物分别为 build/host/ivsbox-provision 与 build/arm/ivsbox-provision
  （运行时需工厂模式标记存在方可执行，量产后删除标记即关闭入口）

【约定与注意事项】
  - 当前 src/main.c 只是入口占位桩，**功能尚未实现**（见 src/readme.txt）。
  - 身份落点、混淆与校验口径以 功能开发计划.md §S5.5 为准；该计划陈述中的
    分区路径/大小等平台事实应以下列文档与板端实测为准，勿凭印象编造。
