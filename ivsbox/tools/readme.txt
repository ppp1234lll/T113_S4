============================================================
tools  ——  按需工具（非常驻进程），为量产/工装服务
============================================================

【目录作用】
  收纳"按需运行、不常驻"的辅助工具，区别于 src/app（ivsboxd）、media、web、updater
  这些常驻/服务进程。本目录下的工具由顶层 Makefile 统一构建（各自是独立可执行目标，
  复用同一套 mk/ 与工具链），但不在设备日常自启之列。

【文件说明】
  本目录无直接源文件，只有下级工具子目录：
    provision/   出厂工装：写入设备 ID / MAC 等身份信息（见其 readme.txt）

【运行方式】
  make host    构建宿主机版本（产物 build/host/ivsbox-provision）
  make arm     交叉编译板端版本（产物 build/arm/ivsbox-provision）
  （工具运行时通常需要在工厂模式标记存在时方可执行，见 provision 子目录说明）

【约定与注意事项】
  - 工具是"按需"产物：只在需要时运行，不进日常自启。
  - 每个工具一个子目录，子目录内源码放 src/；源码由顶层 Makefile 按目录通配收集，
    子目录不放 Makefile。
  - 涉及设备身份/密钥写入的工具，量产口径与落点以 功能开发计划.md §S5.5 为准。
