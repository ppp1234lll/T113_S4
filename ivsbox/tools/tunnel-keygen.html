IVSBox 远程通道 —— 令牌与访问端配置生成器

离线单文件：不联网、不装东西，双击本文件即可。填两样（设备 SN、令牌）， 它算出 secretKey 并生成运维 PC 要用的 visitor.toml 与 connect.bat。

1. 设备与令牌

同一份令牌要填三处：设备 Web、frps 的 auth.token、这里的 visitor.toml。 少一处都连不上，而且失败现象各不相同（见下方排错）。

2. 服务器与端口

设备侧固定只转发本机 sshd:22；摄像机/文件都在这条 SSH 通道里做。

5. 运维 PC：connect.bat

把 frpc.exe 与 visitor.toml 放在同一个目录再双击 connect.bat。 frpc 不需要安装。

顺序（顺序错了会"连上了但用不了"）

  1. frps 服务端：起 frps，auth.token 设成本页这个令牌，端口 7000。
  2. 设备：浏览器进设备 Web →「远程通道」→ 填 frps 地址/端口 + 粘贴令牌 → 勾「启用通道」→「保存并生效」。 保存后 5 秒内 monitor.sh 会拉起设备侧 frpc（日志 /mnt/UDISK/log/frpc.log）。
  3. 运维 PC：本目录放 frpc.exe + visitor.toml，跑 connect.bat。
  4. 连设备：ssh -p 2022 root@127.0.0.1；传文件 pscp -P 2022 root@127.0.0.1:/mnt/sdcard/snap/a.jpg .
  5. 看摄像机：ssh -p 2022 root@127.0.0.1 -L 9090:192.168.1.200:554， 然后本机 rtsp://127.0.0.1:9090/...。摄像机 IP 是设备所在内网的地址，不是公网。

排错：三种"连不上"分得开

  • 设备侧 frpc 没起：设备 Web 状态卡显示「未开启」，或 ps 里没有 frpc。 看 /mnt/UDISK/log/frpc.log 与 /etc/frp/frpc.toml 是否存在。
  • 设备 frpc 起了但连不上 frps：frpc.log 里是 connect to server error / authorization failed ⇒ frps 地址、端口、或 auth.token 不一致。
  • visitor 连上了却"连不通"：serverName 与 secretKey 两侧不一致。 serverName 必须等于设备的 SN，secretKey 必须等于本页算出的那 16 位。

安全说明

  • 令牌 + SN 就能算出 secretKey，等同于远程入口的一半钥匙，不要贴到群里/工单里。
  • 通道只转发设备的 sshd(22)，frps 上不暴露任何端口给公网扫描（stcp 类型）。
  • 设备侧有有效期闸门：到期由 ivsboxd 与 frp.sh 各自判一次，主控挂了也会关。
  • 本页所有计算都在浏览器里完成，不会把令牌发到任何服务器（可断网使用）。
