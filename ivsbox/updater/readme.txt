============================================================
updater  ——  ivsbox-updater 升级器：验签、双版本切换、回滚
============================================================

【目录作用】
  ivsbox-updater 是升级器进程，按需以 root 运行，负责升级包的验签、安装与双版本
  切换、失败回滚。分工上 ivsboxd **只协调**（收命令/下载/上报进度），验签安装归本
  进程。它独立编译，不参与 libivcore/libivhal/libivmodules 三层业务库链接。

【文件说明】
  本目录无直接源文件，只有下级源码子目录：
    src/    升级器源码（入口 main.c，见 src/readme.txt）

【运行方式】
  make host    构建宿主机版本（产物 build/host/ivsbox-updater）
  make arm     交叉编译板端版本（产物 build/arm/ivsbox-updater）
  （升级流程由 ivsboxd 协调触发；启动包装脚本负责 bootcount 与失败回滚）

【约定与注意事项】
  - 当前 src/main.c 只是入口占位桩，**升级功能尚未实现**（见 src/readme.txt）。
  - 升级包格式、签名算法、双版本切换与回滚口径见 功能开发计划.md §S7.1~§S7.3；
    验签公钥、槽位布局等以架构相关章节与板端实测为准，不得凭猜测编造。
