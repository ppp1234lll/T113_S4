web_ui_redesign —— Web 界面重设计交付目录
==========================================

存放 http://192.168.2.120/ 的 IVSBox Web 界面（ivsbox/web/static/）
重设计相关交付物，交由界面实现者（人或 AI）使用。

内容
  Web界面重设计方案.md   主文档：现状问题、设计规范（Design Tokens）、
                          逐页设计说明、工程落地约束、验收清单
  prototype.html         重设计交互原型（单文件自包含、内置演示数据；
                          哈希路由切换 11 个页面；双击即可打开）
  mock_server.mjs        本地预览服务器（Node ≥ 18 零依赖）：
                          http://127.0.0.1:8020/ 用真实前端代码跑模拟数据，
                          /prototype 打开原型；登录 admin / 88888888
  现状截图/              现有界面 11 屏（真实代码 + 模拟数据渲染，
                          2026-10-19 截取时真机 192.168.2.120 离线）
  设计稿/                重设计后 11 屏（1440×900，由 prototype.html 截出）

定位
  本目录只放设计交付物，不是产品代码；原型与 mock 服务器仅用于
  设计评审与回归对照。产品前端仍以 ivsbox/web/static/ 为唯一源头。
